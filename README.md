A gamified productivity engine with RPG mechanics. Complete quests to earn XP, maintain habit streaks, and avoid offline HP penalties. Features an 8-bit brutalist UI.

Level Up is a standalone, gamified productivity tracker that applies core Role-Playing Game (RPG) mechanics to daily task management. Designed with a strict 8-bit, monochrome brutalist aesthetic, it forces accountability by rewarding consistency with Experience Points (XP) and punishing procrastination with Health Point (HP) damage.

The task engine is built on an Object-Oriented polymorphic hierarchy, handling three distinct quest types (Daily, Deadline, and Habit) that each calculate unique reward multipliers and time-based penalties.

Tech Stack (3-Tier Cloud Architecture):

Frontend (Presentation): Vanilla HTML, CSS, JavaScript, and Chart.js for telemetry.

Backend (Application): Python (FastAPI/Flask) REST API for server-side game logic validation. (In Progress)

Database (Data): PostgreSQL managed via SQLAlchemy ORM. (In Progress)
